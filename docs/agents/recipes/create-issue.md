# Create an issue

1. Run `gh auth status` and confirm a GitHub remote. Without one, stop and explain.
2. Search open issues for duplicates.
3. Ask at most three questions, then read the relevant code.
4. Draft with the Feature or Bug template headings, naming affected files before and after. Add a Mermaid
   diagram only when a flow changes.
5. List unrelated findings separately.
6. Show the draft and wait for a yes.
7. Run `gh issue create --body-file <file>`. Report the URL and the branch name.

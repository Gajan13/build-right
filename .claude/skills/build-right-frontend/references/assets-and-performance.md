# Assets and performance

Docs: `01-getting-started/11-css.md`, `12-images.md`, `13-fonts.md`.

- Set image dimensions or `fill` with `sizes`, and write useful alt text.
- Preload only the LCP image and compress originals.
- Load fonts in the layout and expose them through `@theme`.
- Animate transform and opacity, and respect reduced motion.
- Prefer allow-listed remote image hosts, never a wildcard.

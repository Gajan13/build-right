# Testing

- `npm test` tests the guard. Add a case for every guard change.
- The site has no test runner yet. Don't claim pages are tested because this command passes.
- For pages use the production build plus a browser at 360, 768 and 1280px.
- For forms exercise success, validation, abuse and delivery failure with test data.
- When real logic appears, propose a test runner and wait for dependency approval.
